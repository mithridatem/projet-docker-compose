## cloner le projet
```sh
git clone https://github.com/mithridatem/projet-docker-compose.git
```
## se déplacer dans le projet
```sh
cd projet-docker-compose
```

## installer les dépendances
```sh
cd app
npm install
```
## builder la version de prod (dossier ./dist)
```sh
npm run build
```

## lancer la version de dev
```sh
npm run dev
```
